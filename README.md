# Cafe Sales: Exploratory Data Analysis

Exploratory analysis of a cleaned cafe sales dataset (9,064 transactions, 2023) using Python (pandas, matplotlib, seaborn).

## Files
- `Copy_of_task2_intern.ipynb`: analysis notebook with statistics, charts and insights
- `cafe_sales_cleaned.csv`: cleaned dataset from Task 1

## How to run
Open the notebook in Google Colab, upload `cafe_sales_cleaned.csv`, and click Runtime > Run all.

## Key findings
- Salad, Sandwich and Smoothie generate 55% of revenue.
- Price, not quantity, drives revenue (all items sell about 3 units per order).
- Sales are stable across the year; Wednesday is the weakest day.
- Three days are revenue outliers: 24 Jul, 5 Jan, 6 Jun.
- 31.7% of payment methods and 39.6% of locations are Unknown.
